# TermHub

여러 터미널을 창 하나에 탭/화면 나누기로 띄우는 맥 앱.

## 빌드 & 설치

```bash
./scripts/build-app.sh   # ~/Applications/TermHub.app 에 설치
```

## 단축키

| 키 | 동작 |
|---|---|
| ⌘T | 새 탭 |
| ⌘D / ⇧⌘D | 오른쪽 / 아래로 나누기 |
| ⌘W / ⇧⌘W | 패널 닫기 / 탭 닫기 |
| ⌘] / ⌘[ | 다음 / 이전 패널 |
| ⇧⌘] / ⇧⌘[ , ⌘1–9 | 탭 이동 |
| ⇧⌘R (또는 이름표 더블클릭) | 패널 이름 바꾸기 |
| ⌘= / ⌘- / ⌘0 | 글자 크기 |

## 마우스로 다루기

- 이름표 오른쪽 버튼: 오른쪽에 추가 / 아래에 추가 / 닫기
- 이름표를 끌어서 다른 패널 위에 놓기: 왼쪽·오른쪽·위·아래로 옮기기, 가운데에 놓으면 자리 바꾸기
- 이름표 우클릭: 추가, 이름 바꾸기, 다른 탭으로 보내기, 새 탭으로 떼어내기, 닫기
- 옮겨도 안에서 실행 중인 프로그램은 끊기지 않음

## 에이전트 작업 감지

클로드, 안티그래비티 같은 에이전트가 일하는지 끝났는지 설정 없이 알려줍니다.

- 출력이 계속 나오면 이름표에 스피너
- 출력이 3초 멈추거나 벨/알림 신호(OSC 9, OSC 777)가 오면 초록색 **● 완료**
- 완료된 패널이 있는 탭은 제목 앞에 ●, Dock 아이콘에 개수
- 다른 앱을 보고 있으면 맥 알림 (누르면 그 터미널로 이동). 보기 → "작업 완료 알림"으로 끄기
- 보고 있는 패널에는 표시하지 않음

Claude Code에서 `/config` → 알림 방식을 `terminal_bell`로 바꾸면 더 정확해집니다.

## 테스트용 빌드

```bash
./scripts/build-app.sh --dev   # build.noindex/TermHub Dev.app (설치 안 함, 저장 파일 따로)
```

레이아웃(탭, 나누기, 이름, 폴더)은 `~/Library/Application Support/TermHub/layout.json` 에 저장되고 다음 실행 때 복원됩니다.
